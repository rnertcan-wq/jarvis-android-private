# JARVIS AI 1.0 reconstruction

Recovered from the user's v0.9.9 APK using JADX with anonymous synthetic classes kept separate so the Android source can be compiled. Package is intentionally `local.mertcan.jarvis.next` so v0.9.9 remains installed during testing.

Build with JDK 17, Android SDK 35, Gradle 8.11.1:
`gradle --no-daemon clean testDebugUnitTest assembleDebug`
